DATA & METHODS

Source and calculations.

Source: cbratkovics/nba-game-logs. This project uses the 2021–22, 2022–23, 2023–24, 2024–25, and 2025–26 regular-season player-game files, covering October 19, 2021 through April 12, 2026. One row is one player in one regular-season game. The source excludes DNP rows, playoffs, play-in, preseason, All-Star games, and the NBA Cup final.

The repository combines the five season files into data/player_games.csv. No additional rows are dropped by this website. Counts are row counts. An average is the sum of the selected statistic divided by the number of matching player-game rows. Team and season charts use those player-game averages. The player-scoring finding requires at least 200 player-game rows so a small number of appearances cannot dominate the ranking. Both this report and the dashboard calculate from the same CSV in the browser.
