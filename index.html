01 / THE BIG PICTURE

Five seasons. Eight views.

This report covers the 2021–22, 2022–23, 2023–24, 2024–25, and 2025–26 NBA regular-season player-game logs. Each row represents one player in one game. The report examines scoring, minutes, location, team context, shot volume, rebounding, assists, and three-point attempts.

The five selected season files contain 130,414 player-game rows and all 30 NBA teams.

DATA & METHODS

Source and calculations.

Source: cbratkovics/nba-game-logs. This project uses the 2021–22, 2022–23, 2023–24, 2024–25, and 2025–26 regular-season files, covering October 19, 2021 through April 12, 2026. One row is one player in one regular-season game. The source excludes DNP rows, playoffs, play-in, preseason, All-Star games, and the NBA Cup final.

Counts are row counts. Averages equal the sum of a statistic divided by the number of player-game rows in the selected group. The dashboard performs these calculations directly from the source Parquet file in the browser.
